# Nick Libby — Portfolio

Personal portfolio of Nick Libby: data analytics projects in Python, SQL, and
dashboards, plus selected builds. React site hosted on Cloudflare Pages.

## Status

Stage 0: project scaffold only. Design and content are gated on the blueprint
session (philosophy: art deco; fabric: ASCII art; flavor: retro VHS).

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
```

Output goes to `dist/`, which is what Cloudflare Pages serves.
